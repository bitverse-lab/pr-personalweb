Prototipe v3: coba lima gerakan ini.
  1. Run: garis "executing…" lalu hasil (di versi asli durasinya waktu query sungguhan).
  2. Pindah tab: baris lama keluar ke atas, baris baru masuk; garis biru tab ikut meluncur.
  3. Saklar "plain language": SQL "diterjemahkan" jadi kalimat, kolom kode menghilang.
  4. Tab stack.sql: arahkan kursor ke satu baris, proyek yang memakai lapisan itu menyala di bawah.
  5. Tab projects.sql: klik satu baris, baris itu berubah menjadi kartu studi kasus (Chrome/Edge; browser lain scroll biasa).
